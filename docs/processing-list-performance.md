# 처리중 리스트 성능 및 연결 안내 개선 — 2026-09-14

- 기존 요청은 주문 100개 × 상품 최대 250개의 중첩 데이터를 매 페이지 요청했다. 주문 20개 × 상품 20개로 최초 요청 비용을 줄이고, 더 큰 주문은 별도 상품 페이지 조회로 끝까지 읽는다. 오류·반복 커서·누락 응답은 완료된 리스트로 표시하지 않는다. 대규모 주문에서 실제 시간 감소 비율을 측정한 결과는 아직 없다.
- 주문 페이지를 읽는 동안 해당 상품 SKU의 Odoo 창고 위치 조회를 시작한다. 같은 SKU는 한 번만 요청하며 Odoo 동시 요청은 최대 2개다.
- 전체/상온 주문 필터 결과를 같은 데이터로 만들어 반환한다. 온도 필터만 변경할 때는 재조회하지 않는다. 주문 단위 상온 판정, 수량, 인쇄에 전달되는 주문 목록을 유지한다.
- 새 주문·수량 변경은 '최신 주문 새로고침'으로 다시 조회한다. 조회 시각은 베를린 시간으로 표시한다. 이 페이지의 새로고침은 주문 캐시를 재사용하지 않는다.
- 창고 위치 조회 실패를 '위치 미지정'으로 확정·저장하지 않는다. 처리중 리스트에서 실패 시 재조회 안내를 보여준다. 다른 기존 Odoo 호출자는 strict 옵션을 지정하지 않으면 기존 동작을 유지한다.
- 설정 화면에 고객용 API 연결 카드를 추가했다. 기존 고객 API 경로, 응답, Bearer 인증, 모바일 기본 주소를 변경하지 않았다. 별도 직원용 API와 구분한다.

검증: 서버 40개, 모바일 37개 테스트 통과. 필터 변경 시 재조회 생략/명시적 새로고침 유지, 큰 주문 상품 추가 페이지, 창고 조회 병행, 실패 시 부분 목록 거부, 모바일 조회·토큰 갱신·폴링 포함. production build 통과. 실제 로그인 계정에서의 주문 수와 로딩 시간 비교 및 인쇄/이메일 실행은 미실행.
