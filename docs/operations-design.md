# Processlist 운영 화면 개선 (2026-09-13)

- 주문이 잡힌 상품 목록의 이름은 사용자 지정 명칭인 **처리중 리스트**로 통일한다. 메뉴, 대시보드 진입, 페이지 제목, 인쇄물/발송 안내에 반영했다. 기존 URL과 기능은 유지한다.
- 대시보드: 카드와 반복되던 미처리 주문 안내를 작업 바로가기로 정리하고 최근 검수 활동을 달력보다 먼저 배치했다. 이전 업데이트는 접어서 열 수 있으며, 과거 버전을 최신이라고 표시하지 않는다.
- 검수: 남은 수량/예외 품목 수를 강조하고 스캔 영역을 구분했다. 전체 일괄 완료는 별도 위치로 옮겼으며 기존 동작을 유지했다. 하단 저장 영역은 넓은 화면에서 스크롤 중 유지하고 작은 화면에서는 본문을 가리지 않도록 고정을 해제한다.
- 공통: 입고 예정/운송 중/창고 도착/입고 완료/검수 완료를 구분한다. 지표 카드는 키보드로 진입할 수 있고 검색창은 가용 폭에 맞춘다.

검증: production build 및 기존 테스트 32개 통과. 실제 공통 React/Polaris 컴포넌트를 예시 데이터로 렌더링해 넓은 폭/360px 컨테이너의 시각 배치를 확인했다. 로그인된 Shopify 임베디드 화면에서 검수·저장·인쇄 전체 동작을 직접 실행한 검증은 아니다. 실제 주문/재고 변경이나 이메일 전송은 수행하지 않았다.
